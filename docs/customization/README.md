# Customize without forking the workshop

1. Define the outcome and patterns with [use-case onboarding](../operations/use-case-onboarding.md).
2. Read [overlay and sanitization rules](customer-overlay.md) before adding scenario content.
3. Add the guide, teaching story and deterministic synthetic baseline.
4. Validate references and inspect the page at multiple learning depths.

Use [environment configuration](../operations/environment-configuration.md) for private
bindings, [structured teaching](../../education/README.md) for lessons, and the
[code-reading path](../architecture/code-reading-path.md) before changing shared behavior.
Public overlays remain synthetic; private configuration does not grant write approval.
