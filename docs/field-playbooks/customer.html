GUIDANCE

The authority boundary

Models propose. Deterministic checks validate. Policy constrains. Humans approve. Only an authorized service performs authoritative writes.

  • MCP exposes capabilities; it does not grant permissions.
  • Skills teach procedures; they do not authorize cloud changes.
  • A successful-looking answer is not proof that a tool ran or numbers are correct.

What each tool adds

DOCUMENTED BEHAVIOR

Fabric MCP and Fabric Skills

MCP provides scoped access to available tools and context. Skills provide reusable domain procedures. Together they help the coding assistant discover, plan and explain work without becoming the authority for writes.

DOCUMENTED BEHAVIOR

GitHub Copilot

Use GitHub Copilot in VS Code or CLI to understand the repo, draft transformations, add tests and inspect failures. Check which GitHub.com features and permissions are available before using them.

Power BI and Claude Code
