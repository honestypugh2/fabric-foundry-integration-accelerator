GUIDANCE

Cloud boundary

PLAN → VALIDATE → APPROVE → EXECUTE → VERIFY → AUDIT. Refresh target/readiness, check duplicates, approve the exact operation, independently verify outputs and retain a private audit. A LIVE failure never silently becomes a LOCAL write.

  • Keep real identifiers in ignored private bindings, not source or screenshots.
  • Publication, runtime execution, model changes and report publication are separate approvals.
  • Never regenerate the independent baseline merely to get green.
