# MCP configuration profiles

Opt-in MCP profiles: `offline.json`, `live-readonly.json`, `live-authoring.json` (approval-gated), `fabric-skills.hardened.json`. External servers are pinned (e.g., `@microsoft/fabric-mcp@1.4.0`, `@microsoft/powerbi-modeling-mcp@1.0.0`, `@azure/mcp@2.0.5`). MCP access is not authorization.
