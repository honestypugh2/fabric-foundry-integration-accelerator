## The pieces

- **Semantic model:** the layer that defines tables, relationships and measures for reports.
  In this accelerator it sits on the Gold layer in **Direct Lake** mode, reading OneLake Delta
  tables directly.
- **PBIP (Power BI Project):** saves a model and report as a folder of text files, so they can
  live in Git. Models are written in **TMDL**; reports in **PBIR**.
- **Power BI Authoring (Modeling) MCP server:** lets an agent connect to a model and change
  relationships, measures and descriptions. The **local** version is GA; a **hosted** version is
  in preview.
- **Authoring skills:** `semantic-model-authoring` and the report planning, design, authoring
  and management skills teach the agent the right procedure.
- **Fabric IQ MCP:** a read-only server for asking a model questions with DAX. Good for checks.

```text
 Gold tables (OneLake) ──Direct Lake──▶ semantic model ──▶ two-page report
                                            ▲      │
              Power BI Authoring MCP ───────┘      │ DAX queries (Fabric IQ MCP, read-only)
              (edit, after review)                  ▼
                                      compare with Gold baseline ✔ / ✘
```

## The flow in the HC-01 guide

1. Connect to the model and inspect its seven tables (read-only).
2. **Propose** relationships and measures; stop for review.
3. Apply them, then run DAX checks and compare with the Gold totals.
4. Review the model for best practices and AI readiness (read-only).
5. Plan a two-page report, build it as PBIR, preview it, then publish as a separate step.
6. Final read-only validation with evidence.

## Two ideas to remember

- **Prove numbers, not appearance.** Each measure must match the expected baseline.
- **A local PBIR file is not publication.** Publishing is its own approved step with its own
  evidence.

## Glossary

- **Measure:** a reusable calculation such as Denial Rate.
- **Relationship:** how a dimension (patients, dates) filters a fact (encounters, claims).
- **Baseline:** the expected values computed independently from Gold data.
