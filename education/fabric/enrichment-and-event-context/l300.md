## Build a controlled scratch experiment

Create independently labeled synthetic text and compare a deterministic classification rule
with a candidate model under fixed inputs. Record rejected outputs, per-category errors, model
version and latency. A lookup mock proves orchestration behavior, not AI classification quality.

For event context, run one identified sequence in occurrence order, arrival order and duplicate
replay. Compare the final interpreted state and proposed actions with a predefined reference.
Record event age, rejected stale inputs, duplicate effects and recovery behavior. Keep identity,
rules and event payloads fixed across conditions.

## Inspect failures

Test missing timestamps, conflicting duplicates and a dependency timeout. Do not silently replace
an invalid timestamp with the current time or escalate identity to keep a flow moving.
These are proposed LOCAL studies; live AI functions, Eventstream and Eventhouse execution need
their own tool-specific, authorized verification.
