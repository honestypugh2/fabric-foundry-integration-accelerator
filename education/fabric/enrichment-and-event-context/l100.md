## What is stored, what is proposed?

A batch enrichment job might attach a category to fictional text records in Silver. Its output
needs an agreed schema, quality checks and provenance. An event-driven workflow might use a
recent operational change as context for a proposed investigation. That proposal is not a write.

Event time describes when something happened. Processing time describes when the system saw it.
If an older event arrives late, arrival order alone can produce the wrong conclusion. Repeated
delivery can duplicate work unless the process recognizes the same identified event.

## Choose the simpler path

Use AI enrichment when a derived field genuinely needs model interpretation. Use a deterministic
rule for a fixed threshold. Use event context only when timing matters. The P05 and P07 catalogue
entries describe these choices; they do not mean both live pipelines exist in this repository.
