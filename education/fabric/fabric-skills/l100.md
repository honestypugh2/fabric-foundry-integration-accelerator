## What a skill is

A **skill** is a folder containing a `SKILL.md` file - Markdown instructions with a short
description - and sometimes reference files. When you ask an agent to do something that matches
the description, the agent loads the instructions and follows them.

A skill is **not** a program that runs by itself. It tells the agent what to do; the agent then
uses its own tools (a terminal, an MCP server, Git) to do it.

```text
 You: "create a materialized lake view for silver claims"
   │
   ▼
 Agent (Copilot CLI / VS Code / Claude Code)  ← the HARNESS
   │  matches the request to a skill (spark-cli)   ← KNOWLEDGE
   ▼
 runs az rest / SQL / PySpark / MCP tools          ← EXECUTION
   │  as YOUR signed-in identity                    ← AUTHORITY
   ▼
 Fabric ──▶ result, request IDs, PR                 ← EVIDENCE
```

## What is in Fabric Skills

As of October 2026 the `microsoft/skills-for-fabric` repository (v0.3.18) contains 25 skills,
for example:

- `e2e-medallion-architecture` - plan Bronze, Silver and Gold.
- `spark-cli` - notebook cells, Spark sessions, run triage.
- `sqldw-cli` - warehouse and SQL endpoint DDL, DML and query insights.
- `semantic-model-authoring` - tables, measures and Direct Lake models.
- `git-integration-operations-cli` - Fabric Git integration.

It also has experimental **persona agents** such as `FabricDataEngineer` that route a request
to the right skills.

## Where you install it

- **GitHub Copilot CLI:** add the repository as a plugin marketplace, then install the
  `fabric-skills` plugin.
- **Claude Code:** the same marketplace mechanism.
- **VS Code:** picks up plugins and skills installed for Copilot.
- **APM:** install a single skill for a chosen target.

## Glossary

- **Plugin:** a bundle of skills (and sometimes agents and MCP configuration).
- **Persona agent:** a router agent that chooses skills for you. Experimental.
- **Pre-1.0:** the project is still evolving; pin the version you tested.
