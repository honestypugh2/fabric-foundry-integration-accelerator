## Contracts as executable hypotheses

Write tests for uniqueness, referential integrity, allowed values and measure reconciliation.
Record the input revision, SQL revision and expected counts so someone else can reproduce the
result. Use the repository's synthetic expected files rather than treating an agent answer as
the reference implementation.

## One controlled intervention

Change one Silver rule in a scratch copy. Run the original and candidate transformations over
identical raw inputs. Compare retained rows, rejected rows, diagnostic flags and Gold measures.
Explain why a deliberate correction changes the population; a changed total is not always a bug.

## Implementation boundary

Copilot can propose the rule and tests. Fabric Skills guide the procedure. The designated tool
or extension performs approved execution. A local SQL result remains LOCAL even if its values
match a Fabric table. Preserve raw values for recovery and trace corrections to reviewed rules.
