## A controlled architecture comparison

Prepare held-out synthetic requests and expected route/access decisions. Implement a scratch
deterministic router and compare it with a candidate one-agent arrangement under the same
identity and tool allow-list. Add separate agents only as a third, independently reviewed
condition. Do not change expected decisions after observing failures.

Measure route accuracy, unauthorized disclosures, unsupported answers, tool calls and latency.
Trace the coordinator's selected domain and the backend's authorization decision independently.
A correct route followed by denied access is a legitimate result, not a reason to retry under
an administrator.

## Recovery and implementation status

Timeouts and conflicting domain definitions need explicit outcomes. Preserve provenance for
each returned fact; never combine inconsistent units silently. This is a proposed experiment:
the repository's default demo does not implement or certify this live composition.
