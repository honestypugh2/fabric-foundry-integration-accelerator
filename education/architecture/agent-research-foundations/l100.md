## What each part does

The model generates a response. Context supplies information. The harness manages the
conversation and tools. A tool performs a specific operation. Identity and policy decide
whether that operation is permitted. These roles should not be conflated.

## A worked example

Ask for synthetic sales growth. Without current data, a model may guess. Retrieval can supply
documents, but a numeric question may instead need a governed measure. A Fabric data agent
can supply permitted structured context; Foundry reasons over it. Verify the reported number
against the expected baseline.

## The theoretical connection

RAG motivates augmenting model memory with external information. ReAct motivates incorporating
action observations. Neither means every current agent implements the original paper exactly.

## What proves it?

A proposed tool call is not an executed call. A configured tool is not a result. Inspect the
actual event, execution label, returned context and verification. A LOCAL exercise remains
LOCAL even when it illustrates a live architecture.
