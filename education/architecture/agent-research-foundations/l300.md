## Design an applied-research experiment

State a falsifiable hypothesis: supplying the correct governed context reduces unsupported
numeric claims on a fixed question set. Define failures before running the experiment.
Separate exploratory questions from a held-out evaluation set.

## Implementation protocol

Record input revision, prompt revision, model/deployment version, allowed tools, context
condition, seed where supported and execution labels. Run comparable trials. Evaluate
numeric correctness with the repository baseline and citations with claim-level review.
Record actual tool events, not private chain-of-thought.

## Ablation

Remove one component at a time: repository instructions, a Skill, retrieval or a tool.
Measure task correctness, invalid calls, approvals and reviewer corrections. Do not conflate
the effect of a better model with the effect of adding MCP.

## Authority

Use read-only tasks or separately approved synthetic rehearsals. A research experiment is not
permission to create a notebook, publish a report or deliver a business message.
