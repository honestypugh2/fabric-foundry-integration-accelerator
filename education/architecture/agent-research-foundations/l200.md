## From prediction to evidence

A model's parameters and the current context window play different roles. External retrieval
can supply fresh facts without retraining, but selection can miss the relevant passage or
include misleading instructions. A source citation is useful only if it supports the claim.

## When to use tools

Use bounded tools when a task needs current context, deterministic calculation or an observed
operation. Use a fixed report when it already answers the question. Adding more tools increases
choice complexity and attack surface; it is not automatically an improvement.

## Controlled exercise

Compare three conditions on identical synthetic questions: no supplied context, a relevant
context packet and a deterministic governed result. Record numeric correctness, unsupported
claims and source support. Keep model, prompt, questions and scoring rules fixed.

## Recovery and limits

If context is unavailable, disclose the limitation or permitted fallback. Do not turn a
plausible answer into LIVE evidence. The offline deterministic agent cannot establish how a
language model performs under any of these conditions.
