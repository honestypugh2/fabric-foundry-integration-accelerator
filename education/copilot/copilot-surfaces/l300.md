## Repository files and who reads them

| File | VS Code agent | Copilot CLI | Cloud agent / code review | Claude Code |
|---|---|---|---|---|
| `AGENTS.md` | Yes | Yes | Yes | Via `CLAUDE.md` import |
| `.github/copilot-instructions.md` | Yes | Yes | Yes | No |
| `.github/instructions/*.instructions.md` (`applyTo`) | Yes | Yes | Yes | No |
| `CLAUDE.md` | No | Not relied on | Recognized | Yes |
| `.mcp.json` | Yes | Per-repo MCP supported | No — repository settings instead | Yes |
| `.claude/skills/` | Yes | Yes | Yes | Yes |

Copilot Chat on GitHub.com reads `copilot-instructions.md` but not `AGENTS.md`. The cloud agent
reads instructions from the pull request's head branch.

## This repository's MCP configuration

```json
{
  "mcpServers": {
    "microsoft-learn": { "type": "http", "url": "https://learn.microsoft.com/api/mcp" },
    "ffia-local": { "type": "stdio", "command": "uv",
                    "args": ["run", "--frozen", "ffia", "serve", "mcp"] }
  }
}
```

`microsoft-learn` grounds answers in documentation (needs network). `ffia-local` exposes typed,
read-only and plan-only tools over synthetic data — no approve, execute, SQL or shell tool.

## Working on each surface

**VS Code agent mode.** Open the repository, trust the two servers, then ask the agent to call
`inspect_medallion_architecture`. Tool prompts appear before each call.

**Copilot CLI.**

```bash
copilot                       # interactive; Shift+Tab toggles plan mode
copilot -p "Summarize silver/silver_patients.sql" --deny-tool 'shell(git push)'
```

**Cloud agent.** Open an issue with `.github/ISSUE_TEMPLATE/agent-task.yml` (plan first, writes
limited to a change PLAN). Configure MCP in repository settings, read-only only. Review the pull
request like any other.

**Copilot app.** Preview: documentation only in this accelerator.

**Copilot SDK.** P24; an Agent Framework comparison is not yet included in this accelerator.

## Installing Fabric Skills (optional, online)

```text
/plugin marketplace add microsoft/skills-for-fabric
/plugin install fabric-skills@fabric-collection
```

Pin to a release tag and review its MCP configuration before use; replace it with
`ffia mcp render fabric-readonly --client copilot-cli` and keep `fabric-authoring-gated` opt-in.
