## Instruction resolution

- Copilot supplies personal, repository (path-specific, repo-wide, then `AGENTS.md`) and
  organization instructions **together**. Conflicts are not resolved deterministically by the
  model, so contradictory files produce unpredictable behavior. Keep one rulebook and summarize
  it, as this repository does.
- Multiple `AGENTS.md` files are allowed; the nearest one in the tree wins. The Use-Case Guides
  under `guides/` use this for scoped rules.
- The cloud agent and code review read the **head branch** of the pull request — a pull request
  can change the instructions it is reviewed with. Protect instruction files with CODEOWNERS.

## MCP behavior per surface

| Surface | Configuration | Approval | Notable limit |
|---|---|---|---|
| VS Code | `.mcp.json` (portable) or user profile | Trust on first use, then per-tool prompts or auto-approve rules | `.vscode/mcp.json` deprecated for agent-host sessions |
| CLI | `~/.copilot/mcp-config.json`, per-repo config | Per-tool prompts; allow and deny rules | Allow-all flags remove the gate |
| Cloud agent | Repository settings JSON; secrets prefixed `COPILOT_MCP_` | None per call | OAuth-based remote MCP not supported; firewall excludes MCP processes |
| App | Shared runtime | Mode-dependent | Autopilot removes prompts |

An enterprise MCP allow-list in managed settings applies across surfaces and fails closed on a
malformed configuration.

## Failure modes

| Failure | Where | Control |
|---|---|---|
| Write-capable MCP tool in the cloud agent | Cloud agent | Read-only or offline tools only; audit the configuration via the REST API |
| Instruction tampering in a PR | Cloud agent, code review | CODEOWNERS on instruction files; human review |
| Autopilot runs a destructive step | App | Sandbox with synthetic data; never against a real workspace |
| Wrong tenant from a stale sign-in | CLI, VS Code | Target pinning; check `ffia demo check` and runtime status first |
| Allow-all tools in a script | CLI `-p` | Explicit allow lists; deny pushes and deletes |

## Embedded agents (P24)

The Copilot SDK exposes custom tools, MCP, hooks and OpenTelemetry tracing. An embedded assistant
is a product: it needs its own identity design (app identity or on-behalf-of), approvals inside
the app, evaluation and audit — the same control plane this accelerator demonstrates with its
API.
