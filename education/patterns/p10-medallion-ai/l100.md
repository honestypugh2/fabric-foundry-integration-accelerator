## What it is

The **medallion architecture** refines data in layers, each with one clear job:

```text
source files ─► raw ─► Bronze ─► Silver ─► Gold ─► semantic model ─► reports / agents
                 kept     typed      business   measures and
                 as-is    and clean  shaped     vocabulary
```

- **Raw:** the files exactly as delivered (here: seven synthetic CSVs).
- **Bronze:** the same data loaded into tables, untouched, so you can always replay.
- **Silver:** columns get real types, duplicates are handled, and problems are *flagged*, not
  hidden (for example a blank charge or a vital sign outside a plausible range).
- **Gold:** tables shaped for questions people actually ask, at a stated grain such as "one row
  per encounter".
- **Semantic model:** names, relationships and measures such as *Average Length of Stay*, defined
  once so every report and agent uses the same math.

## Where AI fits

AI is a fast assistant, not the referee:

- It can **profile** a new file and suggest column types.
- It can **draft** a notebook or a SQL transformation.
- It can **explain** why a quality check failed.
- Fabric **AI functions** can classify or summarize text columns.

But a **test** decides whether data is correct, and an **expected baseline** decides whether a
number is right. A model's opinion never replaces either.

## Key ideas

- Agents read **Gold and the semantic model**, never Bronze.
- **Direct Lake** lets a Power BI semantic model read Gold Delta tables in OneLake without
  copying them.
- In this repository everything runs locally on synthetic data and is labeled `LOCAL`.
