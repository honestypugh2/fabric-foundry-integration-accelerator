## Enforcement details

- **Determinism.** The generator is seeded; `ffia data generate --check` fails on any byte
  difference in the committed CSVs, so an AI-edited fixture cannot slip in.
- **Exact diagnostics.** Each injected quirk has a known count. Silver diagnostics must equal it;
  "close enough" is a failure. This catches both under-detection and over-correction.
- **Ratio of totals.** Measures such as average length of stay divide summed totals, never
  average pre-aggregated averages. Silver keeps the actual discharge date (never encounter date
  plus LOS) and flags rows where recorded LOS disagrees with it (`is_los_consistent`).
- **Tolerance gate.** `EvaluationService` compares each measure with an absolute tolerance from
  the overlay's `evaluation_thresholds` (`measure_absolute_tolerance`, `minimum_pass_rate`). The
  example overlay requires a 100% pass rate.
- **No free-form access.** MCP and REST reads are typed operations with a row cap; agents cannot
  issue arbitrary SQL against any layer.

## Failure modes when AI is in the loop

| Failure | How it shows up | Control |
|---|---|---|
| Plausible but wrong SQL draft | Measure drifts by a small amount | Baseline comparison fails |
| "Helpful" cleanup deletes bad rows | Diagnostics count drops | Exact-count diagnostics |
| Baseline regenerated to match a bug | Baseline diff in the PR | Baseline changes need an owner's review |
| Agent reads Bronze for an answer | Duplicates and untyped values in the answer | Layer permissions; Gold-only grounding |
| AI function output treated as fact | Enriched label overwrites a source column | Write enrichment to new, labeled columns |
| Direct Lake falls back silently | Slower queries, different security path | Choose and document the fallback behavior |

## Threats

Prompt injection can hide in free-text columns (for example clinical notes in the synthetic set).
Any AI function or agent reading them must treat the text as data, not instructions, and its
output must never drive a write without the governed change flow (P08).

- The reference DAX must be evaluated in a tenant and compared with the baseline:
