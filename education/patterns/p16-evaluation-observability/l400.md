## Enforcement details

- **Comparison semantics.** `compare` uses an absolute tolerance; `None` equals only `None`, so a
  measure that should be blank cannot pass as zero and vice versa.
- **Gate arithmetic.** `gate_passed` is true only when at least one measure was compared **and**
  `pass_rate >= minimum_pass_rate`. An empty submission cannot pass by vacuous truth.
- **Provenance.** Without `observed`, values come from the local provider and the label it
  reports. With `observed`, the source becomes `caller-supplied` and the evidence is
  `REQUIRES TENANT VALIDATION`, whatever label the caller claims.
- **Honest envelopes.** The execution envelope validator rejects a non-cloud label that claims
  `cloud_operation_performed`, a `LIVE` label without a cloud operation, `LIVE` in `OFFLINE`
  mode, a non-cloud label without a `simulation_notice`, and `fallback_used` without a reason.
- **Correlation hygiene.** A supplied `X-Correlation-ID` is accepted only if it is 32 lowercase
  hex characters; anything else is replaced, which stops log injection through the header.
- **Redaction.** Audit details and logs pass through redaction for tokens, secrets, e-mail
  addresses and GUID-like identifiers before they are stored.

## Failure modes

| Failure | Symptom | Control |
|---|---|---|
| Baseline edited to match a bug | Gate passes, numbers wrong | Owned baseline; review baseline diffs |
| Tolerance loosened quietly | Drift accepted | Thresholds live in a reviewed overlay |
| Evaluator drift (model-graded) | Scores change without code changes | Pin evaluator versions; re-calibrate |
| Lost correlation across hops | Audit trail has gaps | Propagate the ID into agents, tools and traces |
| Mislabeled fallback | `HYBRID` shown as `LIVE` | Envelope validation + `fallback_used` in audit |
| Evaluating with preview evaluators only | Unstable gate | Use them to inform; gate on GA and deterministic checks |

## Threats

Prompt injection can try to make an agent *report* success. Deterministic gates do not read the
agent's narrative; they recompute or compare values. Audit records are written by the platform,
not by the model.

## Production gaps

- OpenTelemetry spans for agents, MCP tool calls and providers, exported to Application Insights,
  arrive with Agent Framework in Phase 6.
- The local JSONL audit store is append-only by convention; production needs an immutable sink
  with retention and access controls outside the application.
- Model-graded evaluation datasets, thresholds and red-team runs must be designed per use case and
  **require tenant validation** in Foundry.
