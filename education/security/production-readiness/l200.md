Choose a fictional overlay alias, a supported synthetic profile and existing guides. Review
`schemas/customer-overlay.schema.json` and `docs/customization/customer-overlay.md`.
An overlay marked non-synthetic is rejected. Its permitted writes must remain inside global

Keep preview flags false until a reviewed development experiment needs them.

## Trace one request

The browser calls the loopback API, which delegates to services and provider ports. An agent may
read governed data through a narrow tool and propose a change. Validation checks policy/scope;
a human approves; a separate writer executes. Tool output cannot approve the proposal.
Every result reports its provider, execution label and fallback. Audit and trace correlation
help explain what happened, but local JSONL is not tamper-proof production storage.

## Inspect release and usage evidence

Run the agent evaluation explicitly offline:

```bash
FFIA_ENVIRONMENT=offline FFIA_FABRIC_LIVE=0 FFIA_FOUNDRY_LIVE=0 ffia agents eval
```

All five cases must pass with expected grounding; fallback responses fail the gate.
Inspect the quality, CodeQL and release workflows. They create artifacts only, not cloud
deployments. Check actual workflow results and alerts before publication.

For live use, choose least-privilege identities, test RLS/OLS denial cases, configure budgets and
monitor actual model/tool usage. Do not assume an admin demo proves least-privilege access.

## Apply the three patterns deliberately

For P14, draw permitted browser, API, Fabric and Foundry network paths and identify the read,
approval and writer identities separately. Validate allowed and denied paths with non-admin roles.
For P15, decide whether shared consumers justify APIM; define authentication, quotas, tool
allow-lists and upstream authorization independently. A gateway success is not a successful
backend permission check. For P18, select a fictional overlay and verify that it narrows global
policy and retains approval. These are reviewed designs until tenant checks actually run.
