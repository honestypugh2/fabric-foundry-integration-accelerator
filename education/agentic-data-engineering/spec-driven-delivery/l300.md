## Implement with traceability

For each requirement, record its task, affected contract, smallest relevant test and required
output. Keep dependency order explicit. Build against existing provider ports; do not put
business rules into routes or duplicate them in React.

## Verification loop

Run targeted tests, regenerate schemas and fixtures when contracts change, and check privacy.
Converge compares behavior with the original requirement. If a gap remains, add a task rather
than redefining success around the implementation you happened to produce.

## Optional CLI

The verified upstream release is `specify-cli==1.1.3`; installation is optional and requires the
repository's dependency review. This lesson does not claim it has been installed. Compare
scratch-generated Copilot or Claude integration files before introducing them into the project.

## Cloud boundary

An implementation agent may create reviewable local artifacts. Any live mutation still requires
its own exact target, duplicate check, validation, human approval, execution and audit.
