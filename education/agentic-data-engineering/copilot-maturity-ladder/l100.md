## What it is

An AI coding agent such as GitHub Copilot works in a loop: read context, plan, call tools, show
results, ask for approval. For Fabric data engineering it helps you write notebooks, SQL, DAX and
pipeline definitions, inspect tables, and propose changes.

To use it well, separate five things:

```text
KNOWLEDGE  Skills, AGENTS.md, instructions            "how to do it correctly"
EXECUTION  MCP servers, az / fab CLI, Git              "the hands"
HARNESS    Copilot CLI, VS Code, app, cloud agent,     "the agent loop and its permissions"
           Claude Code
AUTHORITY  Entra identity + Fabric roles + policy +    "who may do it"
           human approval
EVIDENCE   Audit record, pull request, operation IDs,  "proof it happened"
           traces, evaluations
```

Skills make the agent **competent**. MCP makes it **capable**. The harness makes it
**productive**. Identity and approval make it **safe**. Evidence makes it **trustworthy**.

## The ladder in plain words

- **L0 Manual** — you do everything.
- **L1 Assisted** — Copilot explains and completes code in your files.
- **L2 Grounded** — Copilot reads repository instructions and real documentation instead of guessing.
- **L3 Skilled** — Copilot follows Microsoft-written Fabric procedures (Skills).
- **L4 Connected** — Copilot looks at real data and items, read-only.
- **L5 Governed change** — Copilot proposes; a human approves; a pipeline applies.
- **L6 Parallel** — several agent sessions work at once, each producing a pull request.

## Human skills you need

- Git and pull requests; basic PySpark, T-SQL and DAX.
- Python with uv and Node.js for local MCP servers.
- For L4–L5: `az login` and a Contributor role in a **dev** workspace. Offline, you need none.
- A Copilot plan; the Copilot app needs preview eligibility.

## Key ideas

- **A tool being available is not permission to use it.**
- Every result says how it was produced: `LIVE`, `LOCAL`, `SIMULATED`, and so on.
- In this repository every level can be practiced **offline** on synthetic data.
