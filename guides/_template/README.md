# New use-case authoring template

**DRAFT / LOCAL authoring.** Copy this folder to `guides/<prefix>-<nn>-<slug>/`. This template
is excluded from the published catalogue. Replace every example before publishing.

| Front-door field | Author supplies |
|---|---|
| Outcome and audience | A bounded problem and measurable result |
| Prerequisites and effort | Local prerequisites; connected prerequisites separately; an estimated scope |
| Offline path | Commands, expected output and no-cloud checkpoint |
| Connected path | Exact provider/server/tool; permission and approval boundaries |
| Completion evidence | Independent baseline and observed outputs, not checked boxes |
| Exclusions | Live certification, production gaps and untested harnesses |

## Required authored assets

- `guide.yaml`: ID equals folder; profile, baseline, patterns, prompts, tools, checkpoints,
  evidence, failure modes and offline equivalents.
- `README.md`: replace this file with the front-door contract and reading order.
- `AGENTS.md` and `CLAUDE.md`: retain root authority and narrow the guide's scope.
- A story in `education/workshop.yaml`: reuse lessons for Executive through L400; link a
  validated presenter handout and describe capability stages and production gaps.
- An existing architecture view with its draw.io PNG, or a new structured view and export.

## Conditional and generated assets

- New data: only when no existing profile fits; add deterministic generation and an independent
  committed baseline through the shared registries.
- New lessons: only for a missing concept; five level bodies, knowledge checks and research brief.
- New MCP profile: only when narrower tooling is needed. Inherit root MCP by default; do not
  copy connection details or broad write permissions into a guide.
- Prompts: generated by `ffia prompts render`, not separately maintained copies.
- API fixtures: generated by `make fixtures`; schemas only change when contracts change.
- Draw.io and generated doc blocks: `ffia diagrams render`; export PNGs from draw.io.
